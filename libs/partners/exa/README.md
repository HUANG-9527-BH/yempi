## 快速安装

```bash
uv add langchain-exa
```

## 🤔 这是什么？

本包包含 LangChain 与 [Exa](https://exa.ai) 的集成。Exa 是一个专为 AI 构建的网络搜索 API，让你能够搜索网络并从任意页面获取干净、可直接使用的内容。
