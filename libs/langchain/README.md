## 快速安装

```bash
uv add langchain-classic
```

## 🤔 这是什么？

遗留的 chains、`langchain-community` 的重新导出、索引 API、已弃用的功能等。

在大多数情况下，你应当使用主包 [`langchain`](https://pypi.org/project/langchain/)。
