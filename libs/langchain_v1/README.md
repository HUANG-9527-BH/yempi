
## 🤔 这是什么？

LangChain 是开始构建由 LLM 驱动的智能体与应用的最简单方式。只需不到 10 行代码，即可连接 OpenAI、Anthropic、Google 以及[更多提供商](https://docs.langchain.com/oss/python/integrations/providers/overview)。LangChain 提供了预构建的智能体架构和模型集成，帮助你快速上手，并将 LLM 无缝融入你的智能体和应用中。

如果你希望快速构建智能体和自治应用，我们推荐使用 LangChain。而当你有更高级的需求——例如需要结合确定性工作流与智能体工作流、进行深度定制、严格控制延迟——请使用 [LangGraph](https://docs.langchain.com/oss/python/langgraph/overview)，我们的底层智能体编排框架与运行时。

LangChain [智能体](https://docs.langchain.com/oss/python/langchain/agents)构建于 LangGraph 之上，从而提供持久化执行、流式传输、人机协同（human-in-the-loop）、状态持久化等能力。（基础用法无需了解 LangGraph。）
