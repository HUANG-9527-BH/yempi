## 快速安装

```bash
uv add langchain-text-splitters
```

## 🤔 这是什么？

LangChain Text Splitters 包含用于将各类文本文档切分为文本块（chunk）的实用工具。

## 📕 发布与版本管理

请参阅我们的[发布](https://docs.langchain.com/oss/python/release-policy)与[版本管理](https://docs.langchain.com/oss/python/versioning)政策。

我们建议将版本固定为特定版本，以避免在我们发布新测试时破坏你的 CI。同时建议定期升级到最新版本，以确保你始终拥有最新的测试。

不固定版本则意味着你始终拥有最新的测试，但如果我们引入你的集成无法通过的测试，也可能会破坏你的 CI。
